## 复现

先按 README 启动标准模式，确保 Transformer v1 已入库，然后在 `frontend/` 运行：

```powershell
node e2e/recordingReadiness.mjs
```

脚本只允许本地地址，阻断页面误触生成式请求；PDF、综述原文、图谱和图表都由实际服务返回。已有人工研究判断不会被覆盖。默认本机 Edge 无头运行，使用仓库已有 playwright-core。
