# 扫描表格与图区域验收（2026-09-15）

## 实现范围

本阶段在既有 PyMuPDF + Tesseract 选择性 OCR 解析器上增加轻量版式恢复，不引入额外模型或 Python 依赖。

- OCR 页出现 `Table N / 表 N` 图注时，分析页面栅格中的横纵线交点并恢复有框表格；
- 复用页面级 OCR 词坐标填充单元格，对仍为空的单元格执行最多 64 格的局部二次 OCR；
- OCR 页出现 `Figure N / 图 N` 图注时，从图注上方相邻墨迹带恢复图区域坐标；
- 整页扫描底图继续被面积规则排除，不作为 Figure 输出；
- 表格、单元格、图区域和图注均沿用原有 Document AST 坐标与锚点结构。

候选检测由图注明确触发，因此普通扫描正文页不会执行栅格线扫描，也不会无依据生成表格或图对象。

## 当前边界

- 当前算法面向带编号图注的有框表格和图表，不宣称覆盖无框表格、跨页表格或复杂合并单元格。
- 图区域默认位于 Figure 图注上方；图注在图上方或页面侧边的非标准版式需要额外方向判定。
- 单页超过 64 个表格单元格时只使用页面 OCR 词坐标，不触发逐格 OCR，以限制耗时。
- 本轮使用官方 Transformer 内容构造的扫描替代样本；收到组委会原始 `1706.03762v1_img.pdf` 后必须复跑验收。
