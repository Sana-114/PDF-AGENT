## 修复及边界

PDF 技能用于完整原页对照：看到的柱形图与解析得到的超长矩形不同，不能把后者直接当成可见表格线。原生图形路径实际延伸到绘图区之外，PDF 的裁剪指令使超出部分不可见；旧解析未处理裁剪，图形 bbox 越过正文，导致真实表格与图区错误归属。

- 以流式 `get_cdrawings(extended=True, callback=...)` 读取可见路径，按层级维护裁剪范围，支持嵌套、同级恢复和空裁剪。保留真实零宽／零高绘制规则。
- 表格检测只保留原有线段的可见部分，不沿裁剪边界凭空补框；局部矩形／四边形拆成实际可见边。矢量图 bbox 与表格采用同一可见路径入口，不保存稠密曲线的大型 payload。
- 图题与近邻表题的例外仅适用于明确底部被裁剪的柱形图，且表题在上、图题在下；不因普通彩色表格或一般曲线就放宽排除。
- 写作提示保留评估协议；对于所引非参考条目明示 few-shot linear 与 full fine-tuning 区别的性能陈述，缺少前者时单独暂缓，并显示原因。方法事实与参考文献条目不因此误拦。
- 显示送入写作服务的事实预算及每篇超量，而不是先删除问题句再隐藏超量。新增正反例，复用现有解析／回放驱动，不新增同功能脚本。

当前 native `1.26.4-layout103`，OCR base `1.26.4-ocr-layout98`（实际 OCR 带配置签名）。裁剪使用 scissor 包围矩形，不是任意曲线裁剪蒙版的像素级重建；保守协议规则也不是通用语义蕴含判定。
