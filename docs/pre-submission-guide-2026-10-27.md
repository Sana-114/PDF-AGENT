## 版本、运行和数据

当前源码从工作目录打包，包含未提交修复；不使用只含旧 HEAD 的 git archive。Git 基线 a119f5609cda544e5d587588c5a338051da129a1，分支 codex/stage94-official-failed-qa-retest。既有历史见 https://github.com/Sana-114/PDF-AGENT ，本次不更改分支、不提交或推送。源码快照及清单用于定位预提交内容；正式发布前仍需完成版本冻结。

解压源码 ZIP 后进入 PaperPilot-source。复制 .env.example 为 .env、.env.bge.example 为 .env.bge。真实 DeepSeek 设置：LLM_PROVIDER=deepseek，LLM_MODEL=deepseek-flash，LLM_BASE_URL=https://api.deepseek.com，LLM_API_KEY 填自己的密钥。执行 `pwsh -File scripts/start.ps1 -Mode standard`；兼容 NVIDIA GPU 可添加 `-Gpu`。默认前端端口 3000，实际以配置及启动日志为准。环境模板默认为 mock，不能把默认模式当成已接入真实模型。

精简包保留运行配置、Dockerfile、依赖锁定、测试用例及其引用的辅助脚本、主要验收入口和技术方案 Markdown。旧草稿、阶段流水记录、视频及 PDF 制作脚本、无保留调用关系的诊断工具不再放入源码包；项目工作目录仍保留这些资料。源码 README 改为提交专用入口，避免引用已经移出的旧文件。模型权重与容器镜像由运行环境下载，官方测试论文由评审自行提供。未包含真实 .env、数据库、上传库、缓存、node_modules、Git 内部目录、原始 API 请求或响应。部分验收与录制脚本面向已有本机数据，干净环境需先配置并导入样本，不能开箱复现原有数据库状态。

较早的技术文档 PDF 是历史版本，不作为本包当前作品介绍；技术方案 Markdown 保留在源码 docs 中，旧日期测试成绩按原范围理解。正式比赛技术 PDF 仍需在版本冻结后统一更新。
