# 作者—年份引用双向导航

2026-10-29。本阶段补齐模块三中此前明确存在的作者—年份引用链接缺口，不改变 PDF 原件，不调用 LLM，不重写已有 AST 或正式文献库。

## 功能与修复

- 后端根据本篇参考文献中的第一作者、年份及可用第二作者匹配正文，支持 `Smith et al., 2020`、`Smith et al. (2020)`、`Smith and Lee (2020)` 等形式及 `2020a/2020b` 后缀。
- 同姓同年存在多个候选时不选第一个；不同年份、缺失年份、多个无法区分的书目日期不强行连接。
- API 保留正文原始摘录、字符偏移、块坐标和页码。引用编号只是内部标识，界面不展示合成的 author-year 编号。
- 前端跨 PDF.js 文本片段匹配，保留原始字符。正文可跳到书目，返回正文及上一／下一处引用沿用已有位置导航。
- 真实 PDF 验收发现原生注释层会遮住文字链接，已在点击捕获阶段识别其下方的有效引用，保留返回来源；没有移除原生注释或强制模拟 DOM 点击。
- 同时修复数字引用被字体切分成多个文本片段后不可点击的问题。

| 真实浏览器 | 三篇上述论文及 Transformer 数字引用，4/4 场景通过 | 不代表所有排版、所有设备均通过 |

| 离线工程检查 | 后端 1,757 项，前端 51 项，TypeScript 和本阶段 Ruff 通过 | 不等于论文问答准确率 |

真实浏览器跳转页：LayerNorm 1→11→1；T5 2→63→2；Reformer 1→9→1；Transformer 2→11→2。已目视检查 LayerNorm 书目原页、T5 正文返回截图。无响应模拟，无云端调用，独立 API／文献库；验收后停止本轮临时服务，原服务不改动。

精简结果见 [验收 JSON](evidence/author-year-navigation-2026-10-29.json)。完整报告与失败截图留在 `backend/tmp/author-year-2026-10-29/`：`corpus-initial.json`、`browser-final-3/`、`regression.xml`。前几轮 Windows 保留端口、Next 遥测启动失败、原生链接截获、换页等待和数字片段问题均保留，没有覆盖历史失败。

## 边界与下一步

机构作者、跨块／跨页引用、OCR 姓名错误、复杂复姓及省略作者的多年份写法仍需专门样本。`Smith (2020, 2021)` 当前只匹配完整作者对应的首个年份，不把孤立年份变成全页可点击标记。数字组合或范围如 `[1–3]` 的完整交互仍未在本阶段实现。

本阶段无需迁移 AST，新后端可从原有书目重新生成链接；需要更新运行中的前后端才能使用新交互。本次未更新先前预提交 ZIP、视频或最终技术 PDF，避免把新功能冒充为旧录制内容。

下一阶段优先处理官方扫描件及教材中的表格／公式结构准确性；多用户推荐与最终统一验收保持在后续清单中。
