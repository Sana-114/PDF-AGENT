## 这次真正推进的内容

- **同版链路取得新证据**：最后候选以真实 HTTP API、当前源码前端、实际 BGE-M3／重排器和 DeepSeek 跑通公开 Transformer 的流式问答、原页高亮、刷新恢复。不是缓存回放，不是只检查“模型已配置”。
- **阅读接口**：三篇 SHA 固定的公开 Transformer／LoRA／QLoRA，67页，内容、目录、参考文献及 PDF Range 只读检查 **3/3**；不是全库39份新重验。
- **反例**：原未报告随机种子问题，本机完整原 PDF 的 absence 前提检查后，一次生成明确保留不足状态，没有编造编号。
- **综述改进**：图谱上下文不再只按中心节点优先，同一预算覆盖不同源／目标；四条关系从同一目标扩为四个不同目标、八个端点。仍逐条要求原页书目身份，不把多样性当作科研继承。
- **生成结构**：改为明确的 `comparisons` 与 `background`，最多六条比较、两条背景、总计八条；同篇多块不能成为跨文。旧 `claims/kind` 保存格式兼容，不重排或改写旧输出；原始模型字段和拒绝记录保留。API 的 claims／themes 格式不变，不新增一套生成器。
- **误拦修复**：明确变量关系 `n小于d` 与 `n<d` 同等识别；不能仅写“短序列更快”。不增加论文名或正确答案白名单。

隔离验收工具扩展现有保存夹具与服务驱动，默认仍关闭云端；真实模型和本机 BGE 各需显式开关。创建全新临时 Qdrant 命名空间，不覆盖正式或旧测试集合；模型原调用有记录及全局上限。新增两题 HTTP 检查复用既有原文身份／反例校验。阅读驱动默认仍是39份，仅显式 `--expected-count 3` 才按三份记账。前端用独立缓存，默认运行配置不变。
