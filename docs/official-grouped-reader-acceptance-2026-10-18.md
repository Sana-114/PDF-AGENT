# 署名与贡献阅读器专项验收

日期：2026-10-18。结论：本轮限定功能通过，不代表所有论文或比赛六模块全部通过。

## 1. 本轮完成

- 阅读器增加“署名与贡献”页签。署名、机构和贡献角色分开显示；贡献名单默认折叠，不列全局作者排名，不累加为独立作者总数，也不猜测逐人与机构的对应关系。
- 增加 `GET /api/v1/documents/{id}/people` 紧凑接口。仅在打开页签时请求，不把整份长文档 AST 传到前端。支持中止过时请求、显式错误及手动重试。
- 原页按钮显示在成员名单之前。每段沿用实际页码、Block ID、BBox 与原文，点击自动翻页、滚动并高亮；跨页名字的完整名单不会被粘贴成某一页的原文。
- 共享来源校验供索引和接口使用：来源文本／坐标必须与 AST 相符，成员须能在各段原文合并后找到。来源缺失、正文冒充贡献名单、不存在的成员、非法坐标均不展示整组，而非静默留下半组。
- 区分旧 AST 未含字段、当前解析未检测到分组、部分来源不完整三种状态。旧库不自动重解析、不清空向量。
- 窄屏按钮增加明确无障碍名称；PDF 画布隔离层叠，避免高亮盖住导航侧栏。验收检查动画结束和真实遮挡，不只检查 `aria-expanded`。

姓名仅合并换行，重音字符仍沿用 PDF 文本层，并在界面提示核对原页。这不是所有姓名 Unicode、逐人机构或贡献事实的完整准确率验收。

## 3. 原失败与证据

所有原失败保留，不覆盖为成功：

1. 首次全量回归缺少测试进程的 `OCR_TESSDATA`／`TESSDATA_PREFIX`，6项环境失败。指定已存在的语言包后完整通过，未下载模型或更改正式配置。
2. 初次类型检查发现高亮标签的可空值处理，修复后类型检查通过。
3. 首次浏览器脚本按页码模糊选择署名按钮，匹配同页两个片段，未执行跳转；改为实际Block ID＋页码精确选择。该项是脚本错误，不冒称产品坐标错误。
4. 早期窄屏记录只检查状态与坐标，截图捕获了侧栏过渡及高亮遮挡；最终添加层叠隔离和动画／命中元素检查，使用新目录保存结果。
5. 临时Next开发服务首次因遥测配置写入用户目录失败退出；仅给临时进程设置 `NEXT_TELEMETRY_DISABLED=1` 后正常，不更改用户全局配置。

原始产物在 `backend/tmp/official-grouped-reader-2026-10-18/`（不提交官方PDF和大体积临时数据）：

- `backend-tests.xml` 保留首轮6项环境失败；`backend-release.xml` 为最终1,386项回归。
- `fixture-release/` 为最终新解析、19项专项、SQL／AST／PDF及39文件SHA记录。
- `browser-first/` 保留按钮选择器失败；`browser-source-final/` 为层叠增强前记录，不作为最终视觉结论。
- `browser-release/` 为最终10项浏览器报告、紧凑接口输出和桌面／窄屏截图；注入状态独立计数，不冒充额外官方PDF验收。
- `frontend-final.xml` 为42项前端离线测试。[公共机器摘要](evidence/official-grouped-reader-acceptance-2026-10-18.json)记录源码和产物SHA。

复现入口已纳入项目：后端 `backend/scripts/verify_official_grouped_contributors.py`、浏览器 `frontend/e2e/groupedContributors.mjs`。前者需Python依赖及 `PYTHONPATH=backend;backend/scripts`；后者需前端依赖和Edge。浏览器脚本仅接受专用回环端口3238／8038，并拒绝所有API生成／修改请求。示例：

```powershell
python backend/scripts/verify_official_grouped_contributors.py --corpus-dir 科研小助手/pdf --output-dir backend/tmp/grouped-reader-new-fixture
# 用本机8038的API连接该目录的acceptance.db、uploads、parsed，设置FRONTEND_ORIGIN=http://127.0.0.1:3238。
# 在3238启动当前前端，设置NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8038/api/v1。
node frontend/e2e/groupedContributors.mjs --fixture backend/tmp/grouped-reader-new-fixture --output backend/tmp/grouped-reader-new-browser
```

输出目录必须尚不存在。最终浏览器与后端使用本轮源码，前端为源码开发服务；**不是最终standalone镜像或公网验收**。本轮临时服务已停止，Next自动增加的临时类型路径已撤回；既有3200界面／Docker／正式数据未替换。
