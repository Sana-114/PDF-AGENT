# 无框表格与公式候选验收（2026-09-16）

## 无框表格恢复

解析器仅在可信 `Table N / 表 N` 图注下方建立候选区域。候选区域内按词坐标恢复文本行，再以行内水平间距拆分单元格；只有至少两行重复出现同一列数时，才以这些行的列起点中位数建立列锚点。已有矢量网格与无框候选按区域包含率去重。

图注分类同时排除 `Table 2 summarizes ...`、`Figure 3 shows ...` 等以编号开头的正文句子，避免正文后续段落被误构造成表格。

### Transformer v1 实测

| 表格 | 页码 | 结构 | 结果 |
| --- | ---: | ---: | --- |
| Table 1 | 6 | 6 行 × 4 列 | 恢复 Layer Type、Complexity、Sequential Operations、Maximum Path Length |
| Table 2 | 8 | 13 行 × 5 列 | 恢复 Model、两列 BLEU、两列 Training Cost |
| Table 3 | 9 | 7 行 × 3 列 | 保留现有矢量网格结果，与文本候选去重 |
| Table 4 | 9 | 6 行 × 3 列 | 保留现有矢量网格结果，与文本候选去重 |

完整 15 页解析输出 4 个可靠表格，无表格警告，耗时 4.864 秒。第 41 阶段仅输出第 9 页两个可靠矢量网格，因此本阶段补齐了此前缺失的 Table 1/2。

## 公式候选

公式节点继续保留原始文本、页码、Block ID 和 BBox，并新增：

- `latex`：确定性规范化候选；
- `representation=normalized_latex_candidate`：明确其不是无损数学 OCR；
- Unicode 希腊字母、常见运算符、上下标以及 `sum/sqrt` 的保守转换；
- 原文与 LaTeX 候选一起写入独立公式证据 Chunk。

示例：

```text
原文：β₁ = ∑ᵢ xᵢ · α²
候选：\beta_{1} = \sum_{i} x_{i} \cdot \alpha^{2}
```

Transformer v1 输出 12 个公式文本候选，12 个都具有同位置 LaTeX 候选。

## 自动化验证

- 无边框三列表格可以恢复 3 行、9 个带坐标单元格；
- 以 `Table N summarizes` 开头的正文不会被当成第二个图注；
- 同区域矢量表格和文本表格只输出一次；
- 单个希腊字母的普通说明文字不会被升级为公式；
- Unicode 上下标、希腊字母、求和与乘法符号转换结果稳定。

## 当前边界

- 无框表格依赖可用文本层和重复列对齐，不覆盖扫描无框表格；
- 跨页表格、纵横合并单元格和旋转表格仍需专用结构模型；
- LaTeX 字段是可审计的字符级规范化，不恢复二维分数、矩阵和多行公式结构；
- 本轮不新增大型模型或外部 API，保持普通 Docker 部署路径不变。
