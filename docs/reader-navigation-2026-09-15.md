# 阅读器导航验收（2026-09-15）

## 本阶段补强

阅读器此前已经具备三级标题树、当前章节联动、References 侧栏、数字引用链接和双栏比例同步。本阶段补齐容易在演示中丢失上下文的导航细节：

- 点击 PDF 文本层中的 `[N]` 时，将浏览器点击点按页面原始宽高换算为 PDF 坐标；
- 在同页同标签的多个 AST 候选中选择距离点击点最近的引用块，而不是固定选择第一处；
- 跳到 References 条目时保留原始正文位置，可通过“返回正文”恢复页码和 BBox 高亮；
- 提供“上一处引用 / 下一处引用”，在同一参考文献的全部正文出现位置间循环；
- 双语阅读增加明确的“联动”开关，关闭后两侧可独立滚动，界面持续显示当前状态；
- 页码、标题树、引用条目、正文引用和问答证据继续共用同一 PDF 坐标高亮层。

## 自动化验证

新增纯函数测试覆盖以下边界：

1. 同页同标签存在多个候选时，根据点击坐标选择最近引用块；
2. 标签不存在时不生成伪目标；
3. 上一处/下一处在首尾位置正确循环；
4. 未提供当前位置时，前进从第一处开始、后退从最后一处开始。

前端共 14 项 Node 测试通过，TypeScript `tsc --noEmit` 通过，Next.js 16.3.3 生产构建通过。

## 当前边界

- 当前正文引用识别面向数字标签及有界数字范围，作者-年份格式尚未生成双向链接。
- BBox 来自段落/文本块而非单个字形；高亮保证回到包含该引用的原文块，不宣称像素级包围方括号。
- 双语滚动按当前页可滚动区间归一化；译文段落高度差异很大时，后续可升级为基于 Block ID 的分段锚点插值。
