# 跨论文对比与冲突识别验收（2026-09-18）

## 本阶段目标

在既有单篇/全库 RAG 之上增加专门的多文对比链路，解决“候选全部来自其中一篇论文”和“没有提到就被误判为冲突”两个常见问题。本阶段实现：

- 选择 2–6 篇已解析论文；
- 每篇论文使用同一个问题和同等 Top-K 预算独立召回、向量融合与重排；
- 将各论文证据重新编号为全局唯一 ID，并保留页码、BBox 与检索模式；
- 将 Claim 分类为一致、差异、冲突、单来源或待确认；
- 一致/差异/冲突声明必须实际引用至少两个不同文献，否则自动降级；
- 少于两篇论文命中强证据时拒绝生成跨文献结论；
- Web 端论文多选、覆盖状态、关系统计、原文证据跳转与执行轨迹。

## 自动化验证

新增 3 项后端测试覆盖：

1. 两篇论文分别调用检索器，并将重复的局部 Evidence ID 重排为 `E1...E4`；
2. 两来源一致/差异声明通过，只有单来源证据的伪冲突被降级为 `single_source`；
3. 只有一篇论文命中证据时不调用 Provider，重复文献 ID 被 API Schema 拒绝。

- 前端测试：14 项通过；

## BGE + DeepSeek 真实链路

使用本地已解析的两篇论文：

- `Attention Is All You Need`（arXiv `1706.03762v1`）；
- 《基于无人机俯视视角的骨架动作识别方法研究》。

问题为：“对比两篇论文的研究目标、输入表示和核心方法；只报告有原文证据的差异。”

实测结果：

- 两篇论文各保留 4 条强证据，共 8 条，全部标记为 `reranked`；
- Transformer 证据页为 11、9、8、11，无人机论文证据页为 6、5、5、21；
- `deepseek-flash` 返回 3 条跨来源差异声明和 6 条单来源补充声明；
- 3 条差异声明均同时引用两个不同 `document_id`；
- 未把主题完全不同自动表述为观点冲突，冲突计数为 0；
- Provider 为 `deepseek`，模型为 `deepseek-flash`，无警告。
- `http://localhost:3200/` 返回 200，服务端 HTML 包含对比标题和论文选择器；1440×10000 长页面截图确认新组件与现有工作台共同排版正常。

该验收证明了均衡检索、来源隔离、全局证据编号、生成式分类和服务端来源门禁的真实链路。由于当前两篇论文并非同领域，它不能代替 BERT/Transformer、GPT-1/2/3 或不同实验复现论文之间的专业冲突评测。

## 安全边界

- 论文内容继续作为不可信引用文本进入 Provider，不能覆盖系统规则。
- 服务端只接受本轮 Evidence 白名单中的引用 ID。
- 来源门禁只能证明声明引用了多个文献，不能形式化证明两段文字在逻辑上真正矛盾。
- “未提及”不构成冲突；冲突标签仍应由用户点击原文进行学术核验。
- DeepSeek 不可用时退回抽取式证据展示，不伪装为已经完成的语义对比。
