# 研究工作台界面优化验收（2026-09-21）

## 目标

减少模板化的“AI 产品”观感，让首页首先表现为论文阅读与研究工作台。本轮只调整信息架构、界面文案、颜色和响应式布局，不删除已有功能，也不改变后端 API。

## 调整内容

- 将“科研 Agent、知识库、论文发现、研究分析、创作工具”收敛为“文献问答、文献库、查找论文、研究脉络、研究产出”。
- 首页标题改为“论文阅读，从原文到结论”，删除“智能体、无幻觉、一键、Copilot”等承诺式或营销式表达。
- 清除模块标题中的英文全大写装饰词，用“引用关系、研究综述、写作框架、数据图表”等任务名称替代。
- 将深色高对比任务侧栏改为浅色目录，使用 `01–05` 编号代替“AI、库、寻、析、创”图标。
- 问答消息头像由“AI/你”改为“答/问”，按钮由“发送问题”改为“检索并回答”，状态改为“已核对原文”或“证据不足”。
- 缩短首屏、工作区标题和模块标题间距，使文献问答在常见桌面分辨率首屏内可见。
- 移动端隐藏冗长服务状态文字，仅保留连接状态点；模型名在窄屏做省略显示，任务导航保持横向可滚动。
- 统一低饱和纸张色、白色卡片和墨绿色操作色，移除荧光强调色与大面积深色面板。
- PDF 阅读器、学术翻译、架构图、数据图表和多文对比中的英文装饰标签与“生成”式文案同步收敛。

## 验证

- Next.js 16.3.3 生产构建通过，包含 TypeScript 检查和静态页面生成。
- 前端 14 项单元测试全部通过，覆盖翻译导出、PDF 坐标、引用导航、参考文献选择和联动滚动。
- 使用无头 Edge 检查 `#library` 与 `#writing-workbench`，对应工作区标题和操作按钮均正确渲染。
- 以 1440×1200 检查桌面布局；以 500×1200 检查窄屏布局。主按钮、状态区、任务导航、工作区标题和问答面板均可见，没有页面级横向溢出。
- 验收截图保存在 `backend/tmp/stage59-desktop.png` 与 `backend/tmp/stage59-compact-final.png`，按仓库约定不提交运行时截图。

## 边界

- 模型名称仍保留在服务状态和回答元数据中，便于比赛演示时说明真实 LLM 接入；它不再作为首页宣传主体。
- 图谱、综述和写作等复杂结果页仍保留专业术语与证据状态，因为这些信息直接参与核验，不属于装饰文案。
- 本轮没有重做 PDF 阅读器内部布局，只统一了可见文案；阅读器的版式与交互应在有真实论文打开时继续专项验收。
