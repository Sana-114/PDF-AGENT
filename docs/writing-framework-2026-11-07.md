# 论文框架与真实引用验收

本轮经实际写作接口生成两组框架，覆盖官方 LoRA、QLoRA、ViT 和 CLIP 四份论文。输入副本与保存解析结果的 SHA 均已核验。每组只做一次主生成，视觉主题另有一次模型事实校审，共三次 DeepSeek 调用。

两组均输出 Abstract、Introduction、Related Work 和两条真实书目。四篇题名、作者与首页核对通过，年份为对应预印本年份。六条发布陈述涉及九个原文锚点，规范化后的摘录全部能在所标原页找到，另目视检查四张完整原页。范围为词项检索和 DeepSeek 生成，向量模型本轮没有参与。

## 修复

Related Work 过去会将跨论文比较在每篇论文下面各写一遍。现在按陈述涉及的书目组合分组，联合比较列出全部相关书目和证据，每条陈述出现一次。原始事实、引用编号和逐篇陈述均保留。新增回归约束重复次数、共同来源和单篇来源。两组已保存的真实响应重新经过当前分节函数并通过前端实际导出函数生成下方样稿，这一步没有重新生成事实。

验收脚本改为从 FastAPI 写作入口提交请求，选取范围由隔离 fixture 及 SHA 检查约束。旧脚本把“恰好一次网络调用”当成成功条件，导致视觉主题一次主生成加一次事实校审被误判。现在分别记录主生成与额外调用，要求一次主生成。旧失败报告保留。

视觉主题还暂缓了一条包含无依据数字 11 的模型陈述。原始输出和拦截记录保存在本地验收目录，正文只保留通过现有防护的陈述。科学措辞的两项保留不影响书目真实性，但意味着样稿还需要审校。

当前 Abstract 和 Introduction 使用研究设想加证据组织成框架。较长的指令式 idea 会原样进入框架，使文字显得重复。录制时应使用简洁的研究主题，并展示有出处的相关工作及人工审校过程。
