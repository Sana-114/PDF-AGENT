# 官方论文去重、引用用途与推荐验收

2026-11-06。核对了组委会七页赛题原件，文件 SHA-256 与项目清单一致。复用已保存的 39 份解析结果，逐份比对官方 PDF、归档副本及解析文件的指纹。本轮没有重新解析论文、调用云端模型或更新线上服务。[分项证据](evidence/official-screening-2026-11-06.json)

## 内容去重

在调用生产去重判定前，把所有输入名称替换为同一个无标识名称。生产算法仍可从正文读取 arXiv 身份，另比较题名和正文词串指纹。用原件题名和作者预先划分两个同作品组：Transformer 三份，以及 Emergent Abilities 的两份不同文件。39 份官方 PDF 共有 741 对。

| 预期 | 识别结果 |
| --- | --- |
| 737 对不同作品 | 737 对均未触发重复预警 |
| 4 对同作品 | 命中 3 对，包括赛题指定的原生 v7 与 v1，以及两份 Emergent Abilities |
| 扫描 v1 与原生 v7 | 漏报。题名一致，正文身份未匹配，内容相似度 0.5148，低于无共同身份时的 0.55 门槛 |

保留原门槛。已有[上传和版本选择验收](official-runtime-acceptance-2026-10-13.md)，这次增加的是判定逻辑对全库的误报与漏报检查。结果不能外推到文字被大幅改写的同主题论文。

## 引用筛选

用原页句义给每个引用位置指定用途，同时检查生产返回的书目标签、位置、摘录和块坐标。三个原页共八处。初次 0/8，修复后 8/8。

| 原件及物理页 | 核对结果 |
| --- | --- |
| Transformer v1 第 7 页 | Adam、dropout 和 label smoothing 三处均标为实际使用的方法 |
| Layer Normalization 第 1 页 | 两项引言引用均归为背景。这一段在介绍前人的视觉和语音成果 |
| Scaling Laws 第 12 页 | 一处主要来源归为背景，括号中两条 see also 归为延伸阅读，三者分别对应自己的书目 |

修复支持过去时的方法描述、作者—年份缩写及一对方括号内的多个书目键。一本参考文献如果被引用很多次，返回的五处摘录优先保留能支持其显示用途的证据。默认下钻按整条书目的所有提及汇总，一条文献曾被实质使用时，另有一处泛指不会导致整条剔除。

另外从 ViT 和 FlashAttention 取四处，规则确定后再测。初次按标签判为 2/4。重新核对 ViT 第 5 页，作者明确写明 ResNet 是 baseline CNN，因此修正本次标注，未修改分类器；独立抽查结果为 3/4。FlashAttention 第 7 页说实验采用文献 [17] 的模式，[16] 支持该模式的表达能力。程序把两项都归入方法，后者保留失败。现有筛选适合给评审展示有出处的用途提示，不能凭此推断作者的引用动机。

## 推荐反馈

在新内存库建立两个查询相同的订阅，回放官方 LoRA 与 ViT 题名，固定发布时间与候选，使用项目自带的哈希排序隔离反馈这一变量。A 给 LoRA 点赞前后，B 自身两条反馈都保持中立，但 LoRA 相关度从 0.5000 变为 0.9499，ViT 从 0.5000 变为 0.4785。现有实现使用共享文献库与全局反馈，测试未模拟两个已登录账户。

赛题第 3 页把多用户协同推荐列为实现多用户后可考虑的扩展。它在用户提出的增强目标中仍缺失。单工作区 arXiv 拉取、代码加分、点赞与踩则已有[联网、调度和浏览器记录](official-batch-acceptance-2026-10-18.md)。

## 复现和回归

从仓库根目录，在项目后端 Python 环境中设置 `PYTHONPATH=backend`，运行下列命令。输出目录需为新的 `backend/tmp` 子目录，离线复用既有 39 份 fixture。只要还有漏判、引用错判或反馈隔离不通过，脚本会保存报告并返回 1。

```powershell
python backend/scripts/verify_official_screening.py --fixture backend/tmp/official-functional-acceptance-2026-10-12/local-features-final --corpus 科研小助手/pdf --output backend/tmp/screening-replay
```

完整的 741 对判定在本地 `backend/tmp/screening-nov06/release/pairs.json`。原失败和测试标注更正前的成绩分别保存在 `baseline` 和 `additional`。首次完整回归 1,766/1,767，发现状态测试漏列受支持的「词项检索＋重排」配置。修正测试并在同一配置运行后，1,767 项全部通过。受限环境未完成的测试进程已退出。工程回归和 PDF 内容验收分别计数。
