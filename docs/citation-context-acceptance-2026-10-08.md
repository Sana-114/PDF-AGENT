# 第 74 阶段：引用语境筛选

## 本阶段交付

- 将书目匹配分数与正文引用作用分开呈现。题名、作者、年份匹配不能充当“引用含金量”。
- 从实际引用位置抽取所在句，保存页码、块 ID、坐标、原文；不再用整块开头替代引用语境。
- 标记方法采用、实验基线、背景、泛指和未知。推荐模式先查找方法/基线，跳过只有泛指语境的条目；未知条目不隐藏，供人工核对。
- 只有书目可信匹配、开放 PDF、正文作用推荐三项同时满足时默认勾选。
- 可以切换回原书目顺序（包括泛指引用），也可显式指定引用 ID，不删除原有参考文献。
- 前端可从引用作用说明跳回 PDF 的实际引用块。

## 验证与边界

引用相关测试覆盖逐句归属、同块多条引用、否定表达、多次引用、组合标记、缺少证据和超长 OCR 块。接口测试验证筛选发生在外部检索之前，手动选择可覆盖默认筛选。前端测试验证书目匹配本身不会自动勾选背景/未知条目。

这是有出处的保守规则筛选，并非经过人工标注训练的学术价值模型；复合句、作者年制及隐式引用可能漏判。不能将“泛指”解读为应付式引用或低质量论文，不能声称自动衡量科学贡献。该限制应在技术文档和视频中保留。

## 演示环境恢复

本机 PostgreSQL、Redis、Qdrant 容器原先处于停止状态，导致后端数据库域名解析失败、反复重启。恢复原容器后后端健康检查通过。未删除数据卷；公网部署配置保持不变。
