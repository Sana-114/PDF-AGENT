# 第 75 阶段：未来方向人工核验闭环

## 已实现

- 方向 ID 由原文文献、页码、块 ID 和文本内容生成，不再依赖本轮 F1/F2 顺序。
- 持久化保存继续探索、待核验和人工确认已有解决证据的状态、说明与后续原文。
- 后端核验摘录是否确实存在于指定 PDF 页／块；确认已有解决证据时拒绝无来源、同篇、旧年份和未知年份证据。
- 重新整理综述时恢复记录。来源变更、后续原文移除或年份无法复核时不再据此排除方向，并给出重新核验提示。
- 已人工确认的方向不作为开放方向推荐，仍保留原方向与后续原文跳转，可撤回为继续探索。
- 界面可将方向送入论文检索；用户查找、导入并解析后，再用原文核验，不拿搜索摘要当已解决证据。

## 测试重点

覆盖方向顺序变化后的持久化、重新开放、缺少证据、同篇／更早／未知年份、虚构摘录、错误页码、伪造方向 ID、原文变更和空白说明／摘录。现有综述回归保留。

## 仍然有边界

“人工确认”是用户的研究判断，不代表系统证明科学问题完全解决。规则检索只识别本地较新主题证据；联网检索提供候选论文，不自动认证其结论。跨用户身份隔离和人工核验审计历史尚未实现，记录是当前共享文献库的最新判断。本阶段为新增表，启动会创建表，不修改已有文献表或删除数据。
