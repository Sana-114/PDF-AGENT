## 2. CSV 数值与真实图像检查

真实数据来自官方 `1706.03762v1.pdf` 的**物理第 9 页、Table 3(C)**。逐项核对原生文本及完整页渲染，再独立录入 CSV：

| layers | PPL_wordpiece | BLEU_dev | parameters_million |
| --- | --- | --- | --- |
| 2 | 6.11 | 23.7 | 36 |
| 4 | 5.19 | 25.3 | 50 |
| 8 | 4.88 | 25.5 | 80 |

这些是英德翻译 `newstest2013` 开发集数据；PPL 是 per-wordpiece，不当作其他论文的 per-word PPL 比较。并未据此宣称参数越大必然越好。

六组固定案例为：真实表格折线图、柱状图、三维雷达图，以及合成的同名／缺失记录、未排序日期、重复实验均值／标准误。检查原始预览、源文件 SHA、数值序列、归一化、零值与缺失的区别、误差定义，以及实际导出对象和文件。

本轮发现并修复：

- 雷达导出用名称作为字典键，导致同名记录被覆盖：现在为重复记录分配唯一展示名，保留原预览与全部记录。
- 缺失指标在导出和 SVG 中被补成零：现在保留 NaN／断点，缺失记录不绘制闭合填充区域；真实零值不丢弃。
- 日期折线依上传顺序连线：现在按实际时间排序成对观测，原始预览保持上传顺序；日期不完整时给出警告，不静默丢数据。
- 数值型折线把 2、4、8 当等距类别：现在接口、浏览器和脚本使用真实 X 坐标；时间轴也保留实际间隔。
- 三维雷达导出没有可读刻度：补上每层 0–1 网格与说明，明确层高只区分记录、恒定指标记为 1、面积不代表综合性能。

图注来自 CSV 数值的确定性计算，未调用 LLM 编造趋势。重复实验使用算术均值和标准误；单一样本不能伪造不确定性。雷达图是逐指标 min-max 归一化，不将不同单位混为一个性能分数。

浏览器使用当前主机源代码、真实隔离 API 返回，没有伪造响应体。实际 Matplotlib 3.10.9 依赖安装在本轮临时目录，没有修改全局 Python 环境；运行前核对脚本与当前服务生成的内容完全一致，不执行上传的任意 Python。

六张最终 PNG 已逐张检查，或通过相同 SHA 对应已检查图片；雷达网格修改后的两张重新检查。没有发现中文缺字、关键标题／轴标签裁切。此检查不等于期刊排版认证。

## 3. 推荐：真实 BGE 与离线元数据必须区分

使用官方 ViT、CLIP、LoRA 三份 PDF 的元数据回放，连接实际本地 BGE-M3，操作全新 SQLite 测试库和真实推荐／反馈 API。

首次验收发现：没有踩过论文时，系统把空的负偏好文本发送给 BGE，引发 HTTP 400，并退回基础向量，原先仅检查推荐列表会漏掉该问题。现已跳过不存在的负偏好输入。首次失败记录不删除。

修复后两次实际嵌入分别包含 4、5 个非空输入，均返回 1024 维向量，无 hash 降级。11 项检查包括：三条入库与列表、代码加分公式及来源、点赞／踩保存、再次刷新 0 新增／3 更新、反馈保留、不重复 ID 和订阅范围过滤。

LoRA 代码链接取自原 PDF 首页，不编造 GitHub stars。论文发布日期未知，使用默认时效权重并明确说明，不伪装成最新论文。未运行活跃订阅调度器，也没有把单工作区订阅过滤当成多用户隔离测试。

## 4. 写作：有引用不等于结论准确

本轮实际尝试 **2 次** `deepseek-flash` 生成，使用三份公开官方论文的少量检索摘录，没有发送整篇或私有文档；没有自动重试。

第一次发生网络异常并降级为原文摘录，因此不算生成式写作通过。旧错误信息未保存具体异常类型，不能仅凭空白详情确定是哪个网络环节；已补上超时／传输异常类型、超时设置和不自动重试的诊断信息。

同时修复了英文框架被中文包装问题误导语言判断的漏洞。第二次正常完成，输出 Abstract、Introduction、Related Work、13 条有引用陈述，使用 15 个证据片段并覆盖三篇论文；三条书目的标题、作者和来源身份与原生首页核对通过。这一写作测试使用词法检索及配置的重排器，不单独宣称验证了 BGE 向量召回。

人工辅助逐条审阅后仍保留两个问题：

1. **陈述 2 的跨页限制遗漏。** ViT 物理第 16 页说明一次初始 GAP 尝试表现差；第 17 页及 Figure 9 随后指出，差异由学习率导致，调参后两种分类器表现相近。生成结论遗漏初始尝试与后续条件，不能仅凭正确引用页码放行。下一步需要通用的跨页上下文补充及实验条件保留，不为这篇论文硬编码答案。
2. **书目展示清理。** LoRA 标题仍有断行连字符；核对的年份是 arXiv 首次提交年，不宣称是会议出版年。

另外，“提供的 15 个摘录中未出现组合实验”仅限于输入范围，不能升级成全文或全领域的创新性／空白证明。原生成内容和审阅侧记分别保存，没有用人工修改的输出替代模型原结果。

故本项状态是**生成与出处结构通过，科学表述质量未完全通过**，不能用于宣称无幻觉写作已经全部验收。

## 5. 在线检索：保留实际失败

本轮 5 次实际元数据请求依次为：Semantic Scholar 搜索 429、Crossref 备用检索 200、arXiv 指定版本查询 429、旧 Semantic Scholar 版本 ID 查询 404、arXiv 订阅刷新 429。

Crossref 返回的候选没有确认目标标题与身份。因此成功精确匹配、PDF 下载、在线订阅新增均为 **0**，不使用离线元数据回放填补在线成绩。

已做本地修复并增加测试：区分 HTTP 429 与无效响应；Semantic Scholar 备用查询使用 arXiv 基础论文 ID；明确请求的修订版未经确认时禁止导入，不静默替换为最新版本；导入前校验论文身份和版本。这些修复的网络行为测试使用模拟响应，本轮没有取得修复后的新在线成功证据。
