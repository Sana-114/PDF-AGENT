# 第 69 阶段：应用壳界面验收

日期：2026-09-29

## 目标

在第 68 阶段编辑式视觉基线之上，继续减少首页的宣传页和模板化观感，使首屏更接近可直接工作的科研应用。

## 本阶段调整

- 将大幅首屏改为紧凑的“研究工作区”概览，保留问答、导入和服务状态三个必要入口。
- 移除侧栏的 `01–05` 装饰编号和解释性尾注，让任务名称直接承担导航作用。
- 缩窄侧栏和顶部栏，减少首屏空白与装饰性层级。
- 将导航、工具标题、状态数字和空页面统一为系统无衬线字体。
- 论文回答、综述草稿、翻译结果、引用正文和图注继续使用适合长文阅读的衬线字体。
- 新增统一的请求错误转换，网络不可用时不再向用户暴露浏览器原始英文 `Failed to fetch`。

## 自动化检查

在 `frontend/` 执行：

```powershell
npm test
npm run build
```

结果：15 项测试全部通过，Next.js 生产构建与 TypeScript 检查通过。

## 浏览器验收

使用 Microsoft Edge 无头模式检查 1440 × 1000 桌面视口和 390 × 844 移动视口：

- 首屏标题为“研究工作区”；
- 五个工作区入口均可见；
- 点击“文献库”后地址更新为 `#library`；
- 桌面和移动视口的横向溢出均为 0；
- 后端未运行时显示中文连接提示，不再出现原始英文网络错误。

## 边界

本阶段仅调整应用外壳、工具界面字体与错误展示。PDF 阅读器、引用图谱和代码预览中的功能性深色区域未被移除，生成内容的学术排版也未改变。
