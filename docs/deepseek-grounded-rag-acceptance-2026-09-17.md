# DeepSeek 抗幻觉 RAG 验收（2026-09-17）

## 验收对象

- 公开论文：*Attention Is All You Need*，arXiv `1706.03762v1`；
- 文件 SHA-256：`0a9bff1be3575cf9fe26a4a3d3a9175bc791ecec90de8b9deba4cff75d2b9476`；
- 解析器：`pymupdf-layout 1.26.4`，15 页；
- 生成模型：`deepseek-flash`（Responses 兼容接口）；
- 可重复检索基线：项目内置 BM25，Top-K 6/8；
- 数据集：`backend/evals/attention_v1_grounded.json`。

只使用上述公开论文进行在线生成，没有将本地私有论文发送给外部模型。API Key 仅存在于被 Git 忽略的 `.env` 中。

## 用例

1. Adam 的 `β1=0.9` 与 `β2=0.98`；
2. 训练硬件为一台机器上的 8 块 NVIDIA P100 GPU；
3. 英德翻译为 28.4 BLEU；
4. arXiv v1 的英法翻译为 41.0 BLEU；
5. 论文未报告精确 CO2e 排放量，系统必须拒答且不得生成声明。

第四项同时修正了旧金标准中的版本混淆：41.8 不是 v1 正文报告值，v1 的摘要与 Table 2 均为 41.0。该差异证明版本定位必须参与问答和评测，不能只按论文标题合并事实。

## 验收中发现并修复的问题

- PDF 公式和数字可能被解析成 `β 1 = 0 . 9`、`28 . 4`。评测匹配现会归一化排版空格与标点，但仍保留页码、类型和文献身份限制。
- 旧 v1 金标准错误使用 41.8 BLEU，已依据 v1 摘要和表格校正为 41.0。
- 模型可能补充与问题相关、且确有原文依据的事实。声明接地判定现优先检查金标准；额外声明必须与引用证据共享关键型号/数值，任何新增数值都会判失败。
- 生成提示明确把 PDF 内容视为不可信引用，禁止执行文档内嵌命令，并要求证据不足时返回空声明。

## 当前边界

本次结果证明公开英文矢量 PDF 上的单文精准问答链路可用，不代表扫描 OCR、541 页教材、多文争议综合或所有学科排版均已达到同等指标。后续应在组委会正式数据到位后原样复跑，并增加中文 OCR、跨文献冲突和引用条目精确问答用例。
