## 修复内容

### 结构化输出不能静默选值

新增共享严格 JSON 解码，问答、比较校审、综述校审、学术翻译、分段翻译与进展核对复用：

- 拒绝任意层级的重复字段，例如两次 `status` 或两套 `evidence_ids`，不能让后一个值覆盖前一个。
- 拒绝 `NaN`／`Infinity` 常量，不补括号、不截取任意 JSON 子串，不自动重试。
- 拒绝供应商标记未完成／失败、存在错误或截断信息的响应，即使其中有看似完整的 JSON。
- 不把工具调用、拒绝块、用户消息、非最终消息或多个最终消息静默当成一条有效答案；合法的同消息多文本块仍兼容。
- 保留未发布的实际文本片段、状态和用量诊断。首轮回归发现旧诊断兼容被破坏，已恢复原有截断提示和原始文本保留，未修改旧测试期待来放行。

原始失败中，比较校审实际缺少最后一个右花括号，而非检索没有找到证据。新校审协议改为七个扁平字段，继续要求两篇原文各自的支持性判断；原嵌套格式只供显式离线校验，真实调用不自动回退。格式错误仍会暂缓比较，不通过“补语法”把它改成成功。

### 引文由模型选编号，程序取原文

真实复测发现，要求模型重新抄写原文会反复触发 PDF 断行误拦。例如源片段保留了单词中的换行连字符，模型输出正常拼写，两者含义相同但并非同一个逐字片段。

现在给模型提供当前已选原文的片段编号：模型选择 `goal_span_id` 和证明 `span_id`，程序仅按白名单取回原文。模型不能另写引句、变更编号指向、增加新证据或用自由文本回退。公开 API 返回格式不变，仍为可跳转的 `goal_quote`／`proof.quote`，包含原有页码、Block ID 和 BBox。

后续证据可选择整个段落以保留实验条件，或选择真实连续句子。多处证明来自同一段落是合法的，每处仍单独保留；完全重复、未知编号、伪造引句继续拒绝。内部数值审计汇总这些已核验的片段，避免同编号后一个片段覆盖前一个；汇总文本不冒充一段连续原文发布。

### 已完成实验不再列成未来目标

初版编号协议虽取得机器 3/3，原页复核仍发现模型把邻近的既有实验、定义及整个父段落重复列成待核对目标，不能直接按机器分数放行。

本轮把已有计划识别规则抽到共享模块，综述原提取行为复用同一规则，避免维护两套重复逻辑。可选目标仅限具有明确信号的真实计划句，模型不能选择旁边的已完成测量；缓存重读也重新检查目标资格。隐含计划或超过八个明确目标需人工确认，不自动扩大候选范围。

最后三组分别为：Transformer 复合计划对 ViT 图像摘要、LoRA 层适配计划对 QLoRA 线性层实验、分页测量计划对后来的推理摘要。最后目标数为 2／1／1，邻近已完成实验不再作为新目标出现。

这些只证明本批核心对应和工程流程，仍有文字边界：解释中有时未完整写出 LLaMA 7B／Alpaca 的实验限定，或把“所选摘录没证明”简写为“未研究”。原证明保留完整条件，但不能据此宣称全部自然语言论断已严谨无误，更不能判定全球研究现状。`automatically_resolved` 始终为 `false`，人工结论独立。
