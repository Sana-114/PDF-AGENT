# Agent-first 前端界面验收（2026-09-18）

## 改版目标

旧首页把上传、检索、推荐、图谱、综述、写作、翻译、可视化和问答连续平铺，功能虽然完整，但用户难以判断系统的核心入口。本轮把“基于原文证据完成科研任务的 Agent”确立为首页主角，保留全部既有能力，只重组信息层级。

## 信息架构

- 默认工作区为“科研 Agent / 连续问答”，首屏直接提供带页码、坐标和原文跳转的对话入口；
- 一级导航只保留科研 Agent、知识库、论文发现、研究分析和创作工具五类用户任务；
- 多文对比、订阅推荐、引用图谱、证据综述、写作、翻译、数据可视化与架构图作为区内二级标签按需出现；
- 知识库单独承载 PDF 上传、解析进度、版本提醒、原文阅读和文献 CRUD，避免管理操作干扰问答；
- `#qa`、`#paper-comparison`、`#paper-discovery`、`#recommendations`、`#citation-graph`、`#research-review`、`#writing-workbench`、`#academic-translation`、`#data-visualization` 与 `#architecture-diagram` 深链继续可用。

所有工作台继续使用 `hidden` 状态切换而非销毁组件，因此用户在一级任务区之间切换时，已经填写的查询、选中的文献和生成结果不会被无故清空。

## 视觉与响应式检查

- 桌面端采用深色任务轨与单一浅色工作画布，当前任务、核心 Agent 标识和服务状态具有明确层级；
- Hero 只保留核心主张、两个主操作和三项运行指标，不再重复展示全部能力；
- 980 px 以下任务轨切换为横向滚动导航，760 px 以下压缩 Hero、指标与按钮布局；
- 文档上传、最近文献和其他大型工作台只在对应任务区出现，页面高度随当前任务收敛。

## 自动化验证

- `npm test`：14 项前端测试通过；
- `npm run typecheck`：TypeScript 检查通过；
- `npm run build`：Next.js 生产构建通过，首页完成静态预渲染；
- 使用 1440 px 桌面视口人工检查科研 Agent 与知识库两个任务区，确认主工作区切换和隐藏逻辑正常。

本轮改变的是信息架构和交互入口，不修改后端 API、Agent Harness、检索、引用校验或数据模型。
