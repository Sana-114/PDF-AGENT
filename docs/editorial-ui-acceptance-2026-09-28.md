# 编辑式前端界面验收（第 68 阶段，2026-09-28）

## 目标

在不删除功能、不改变已有 Hash 深链和工作区切换逻辑的前提下，降低界面的生成式产品模板感，让主界面更接近论文数据库、文献管理器和编辑工作台。

## 视觉调整

- 首屏标题从宣传式双行口号收敛为“论文研究工作台”，说明文字直接描述 PDF 管理、原文检索、跨文献比较与写作整理；
- 主色从高饱和深绿改为暖灰纸张底色、深灰正文和单一学术蓝，绿色只保留在服务在线等语义状态；
- 品牌标记、主按钮、侧栏编号、二级导航和状态展示减少发光、阴影、胶囊及大圆角；
- 上传、连续问答、多文对比、学术翻译、数据图表和架构图输入区由深色控制台改为中性编辑表单；
- 引用图谱、PDF 阅读器和代码预览仍保留深色背景，因为这些区域需要画布对比度，而不是装饰性深色；
- 后端未连接时不再暴露英文 `Failed to fetch`，统一显示中文服务连接提示；
- 正式页脚移除 `MVP` 字样，改为说明原文证据与页码定位能力。

## 验证结果

- `npm test`：15/15 通过；
- `npm run build`：Next.js 生产构建、TypeScript 和静态页面生成通过；
- 浏览器桌面复核：文献问答、文献库、多文对比、学术翻译和数据图表工作区可正确切换；
- 浏览器移动端复核：390×844 视口无页面级横向溢出，五个工作区入口均保留在可横向滚动的任务栏；
- 自动交互检查确认页面标题、主题底色、文献库深链和工作区按钮数量正确；
- 本地复核截图位于忽略目录 `backend/tmp/stage68-editorial-*.png`，不将运行时图片加入公开仓库。

## 边界

本阶段调整的是信息层级、颜色与组件表面，不重写业务组件，也不改变 PDF 阅读器中的证据高亮语义色。不同系统的中文字体可能略有差异；正式演示视频仍需在最终部署浏览器、缩放比例和录制分辨率下再做一次画面检查。
